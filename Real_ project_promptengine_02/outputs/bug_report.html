Bug Report

ID: VWO-BUG-001

Inconclusive Generic Error Message on Authentication Failure

Status ● OPEN
Severity Moderate
Priority P2
Component Login Page

Description

During authentication failure (incorrect credentials), the system provides a generic error message that references IP address or location. This feedback is potentially misleading to users who have simply made a typo in their credentials, as it implies environmental or security-based rejection.

Steps to Reproduce

  1. Open a browser and go to https://app.vwo.com
  2. Enter a properly formatted email (e.g., test@example.com)
  3. Enter a password that does not match the account
  4. Click the Sign in button

Actual vs Expected

Actual: "Your email, password, IP address or location did not match"

Expected: A concise message focusing on credential mismatch, e.g., "Invalid email or password."
